# 📜 Scripting

O **scripting** consiste na criação de pequenos programas (scripts) que automatizam tarefas repetitivas, facilitando o trabalho de administradores de sistemas e profissionais de Suporte de TI.

Em vez de executar manualmente diversas ações, um script pode realizar essas tarefas de forma rápida, automática e padronizada.

---

# 🎯 Para que Serve o Scripting?

Os scripts são muito utilizados para automatizar atividades do dia a dia, como:

* ⚙️ Executar tarefas repetitivas;
* 💾 Automatizar backups;
* 🔄 Reiniciar computadores;
* 📂 Criar, copiar, mover e excluir arquivos;
* 📦 Instalar programas automaticamente;
* 🌐 Mapear unidades de rede;
* 📊 Coletar informações do sistema;
* 🔄 Executar atualizações.

A automação reduz erros, economiza tempo e aumenta a produtividade das equipes de TI.

---

# 💻 Principais Linguagens de Scripting

Cada sistema operacional possui ferramentas mais utilizadas para automação.

## 🪟 Windows

### ⚡ PowerShell (`.ps1`)

É a principal linguagem de automação do Windows.

Utilizada para:

* Administração do sistema;
* Gerenciamento de usuários;
* Automação de tarefas;
* Configuração de servidores;
* Execução de backups e atualizações.

---

### 📄 Scripts em Lote (`.bat`)

Também conhecidos como **Batch Files**, são usados para executar comandos automaticamente no Windows.

Exemplos:

* Abrir programas;
* Executar comandos na inicialização;
* Automatizar tarefas simples.

---

### 🖥️ Visual Basic Script (`.vbs`)

Linguagem antiga utilizada em versões anteriores do Windows.

Embora tenha sido substituída pelo PowerShell, ainda pode ser encontrada em sistemas legados.

---

## 🐧 Linux / Unix

### 🐚 Shell Script (`.sh`)

É a principal forma de automação em sistemas Linux e Unix.

Permite automatizar tarefas como:

* 📂 Manipulação de arquivos;
* 👥 Gerenciamento de usuários;
* 🔐 Alteração de permissões;
* 💾 Backups;
* ⚙️ Administração do sistema.

Os Shell Scripts normalmente são executados em interpretadores como o **Bash**.

---

## 🌐 Linguagens Multiplataforma

### 🟨 JavaScript (`.js`)

Muito utilizado no desenvolvimento Web.

Além de páginas web, também pode ser usado para:

* Desenvolvimento de aplicações;
* Automação de servidores;
* Desenvolvimento de APIs;
* Aplicações móveis.

---

### 🐍 Python (`.py`)

O Python é uma das linguagens mais populares para automação.

Sua sintaxe simples e a grande quantidade de bibliotecas fazem dele uma excelente escolha para:

* Automação de tarefas;
* Administração de sistemas;
* Coleta de dados;
* Desenvolvimento de scripts;
* Inteligência Artificial.

---

# 🛠️ Aplicações do Scripting

Os scripts podem ser utilizados em diversas situações, entre elas:

* 💾 Backups automáticos;
* 🔄 Reinicialização de computadores;
* 📦 Instalação de softwares;
* 🌐 Mapeamento de unidades de rede;
* 📊 Coleta de informações;
* ⚙️ Atualizações do sistema;
* 📁 Organização de arquivos;
* 🔐 Configuração de permissões.

---

# ⚠️ Riscos do Uso de Scripts

Apesar de serem extremamente úteis, os scripts devem ser utilizados com cuidado.

Alguns riscos incluem:

* 🦠 Execução de scripts com malware;
* ⚙️ Alteração incorreta das configurações do sistema;
* 🔒 Mudanças acidentais nas permissões de arquivos;
* 💥 Travamentos causados por erros de programação;
* 🚫 Exclusão ou modificação indevida de arquivos.

Antes de executar um script, é importante verificar sua origem e compreender exatamente o que ele faz.

---

# ✅ Boas Práticas

Ao trabalhar com scripts, recomenda-se:

* 🔍 Ler o código antes de executá-lo;
* 📥 Utilizar scripts apenas de fontes confiáveis;
* 🧪 Testar scripts em ambiente de testes antes da produção;
* 💾 Fazer backup antes de alterações importantes;
* 📝 Documentar os scripts criados.

# 📌 Resumo

O **scripting** é uma ferramenta essencial para profissionais de TI, permitindo automatizar tarefas repetitivas e tornar a administração de sistemas mais rápida e eficiente.

Cada sistema operacional possui suas principais linguagens de script, como **PowerShell** no Windows e **Shell Script** no Linux, além de linguagens multiplataforma como **Python** e **JavaScript**.

Embora tragam muitos benefícios, os scripts devem ser utilizados com responsabilidade, sempre verificando sua origem e testando seu funcionamento antes da execução em ambientes de produção.
