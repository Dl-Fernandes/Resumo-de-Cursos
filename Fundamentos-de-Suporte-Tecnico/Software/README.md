# 💻 Software

O **software** é o conjunto de instruções e programas que dizem ao computador como executar determinadas tarefas.

Diferente do **hardware**, que corresponde à parte física do computador, o software é a parte **lógica**, ou seja, os programas e sistemas que controlam o funcionamento dos componentes físicos.

Sem software, o hardware seria apenas um conjunto de peças eletrônicas incapazes de realizar qualquer atividade.

---

# 🧠 O que é Software?

Na arquitetura de computadores, o software é responsável por controlar e gerenciar o hardware, permitindo que o usuário interaja com o computador de maneira simples e eficiente.

Por meio do software, é possível:

* 🖥️ Inicializar o computador;
* 💾 Gerenciar arquivos e pastas;
* 🌐 Navegar na Internet;
* 📝 Criar documentos;
* 🎵 Reproduzir músicas e vídeos;
* 🎮 Executar jogos;
* ⚙️ Controlar dispositivos de hardware.

---

# 🛠️ Exemplos de Software

Existem diversos tipos de software utilizados no dia a dia.

Alguns exemplos são:

* 🪟 Sistemas Operacionais (Windows, Linux e macOS);
* 🌐 Navegadores de Internet;
* 📝 Editores de texto;
* 📊 Planilhas eletrônicas;
* 🎵 Reprodutores de música;
* 🎬 Players de vídeo;
* 🎮 Jogos;
* 📱 Aplicativos para dispositivos móveis.

# 📌 Resumo

O **software** é o conjunto de programas e instruções responsáveis por controlar o funcionamento do computador.

Enquanto o **hardware** representa a parte física da máquina, o software fornece as instruções necessárias para que o hardware execute tarefas e atenda às necessidades do usuário.

Neste módulo serão estudados os principais conceitos relacionados ao software, seus diferentes tipos e as tecnologias utilizadas durante o desenvolvimento de sistemas, formando uma base importante para quem deseja atuar na área de TI.
