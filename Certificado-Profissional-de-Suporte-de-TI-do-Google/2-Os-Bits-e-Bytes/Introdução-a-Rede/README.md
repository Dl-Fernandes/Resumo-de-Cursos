# 🌐 Introdução à Rede

## 📖 Apresentação

Seja bem-vindo ao módulo **Introdução à Rede**.

Nesta etapa do curso serão apresentados os conceitos fundamentais das redes de computadores, que servirão como base para todos os demais conteúdos do curso.

Antes de compreender protocolos, serviços de rede, roteamento ou solucionar problemas de conectividade, é importante entender **como os computadores se comunicam** e quais modelos são utilizados para representar essa comunicação.

Ao longo deste módulo conheceremos os dois principais modelos de referência utilizados em redes de computadores:

- 🌐 Modelo TCP/IP;
- 🏛️ Modelo OSI (Open Systems Interconnection).

Também veremos como esses modelos se relacionam e quais são suas principais diferenças.

Este conhecimento servirá como base para os módulos seguintes, onde estudaremos protocolos, equipamentos, serviços de rede e técnicas de diagnóstico de problemas.

---

# 🎯 Objetivos

Ao concluir este módulo, você será capaz de:

# 🎯 Resumo

A comunicação entre computadores acontece por meio de protocolos organizados em camadas.

Para facilitar o entendimento desse processo, utilizamos dois modelos de referência:

- 🌐 **Modelo TCP/IP**, utilizado na prática em praticamente toda a Internet;
- 🏛️ **Modelo OSI**, utilizado como modelo conceitual para estudo, padronização e solução de problemas.

Dominar esses modelos é o primeiro passo para compreender como os dados trafegam pelas redes, como os protocolos trabalham em conjunto e como identificar problemas de comunicação entre dispositivos.

Este módulo servirá como alicerce para todos os demais conteúdos do curso e para sua formação como profissional de Redes e Infraestrutura de TI.
